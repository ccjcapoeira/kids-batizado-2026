# キッズバチザード2026 スマホ閲覧ページ

ポスターのQRコードから開く、スマホ向けの1ページ案内です。

## 公開URL

公開前です。GitHub Pages用の公開リポジトリを作成後、ここにQR用のHTTPS URLを記載します。

## ファイル

- `index.html` — 本番ページ
- `styles.css` — デザイン

画像や外部ライブラリを使わない静的HTMLです。`index.html`を直接ブラウザで開いて確認できます。

## 更新方法

1. 確定情報だけを `index.html` に反映する
2. スマホ幅（390pxを基準）で、日付・会場・見学無料が最初の画面に入ることを確認する
3. 料金・申込フォーム・申込締切は、確定して次段階の告知を出すまで追加しない
4. 地図・メール・電話などのリンクを確認してから公開する
